PUBLICAÇÃO NO GITHUB
1. Extraia este ZIP no computador.
2. Abra o repositório https://github.com/yuridelestro-collab/ferramentas-pedidos
3. Na guia Code, escolha Add file > Upload files.
4. Envie o CONTEÚDO desta pasta diretamente para a raiz do repositório. Não envie a pasta externa como uma única pasta.
5. Preserve a pasta assets e seus arquivos PNG.
6. Clique em Commit changes e aguarde o GitHub Pages publicar a alteração.

ARQUIVOS QUE DEVEM FICAR NA RAIZ DO SITE
- index.html
- taskpane.html
- commands.html
- commands.js
- config.js
- dialog.html
- assets/ (pasta completa)

O ZIP também inclui manifest.xml, que já contém as URLs do seu GitHub Pages. Ele pode ficar no repositório, mas para instalar o suplemento você deve baixar esse arquivo para o computador e carregá-lo no Excel.

REGRAS IMPLEMENTADAS
1) IMPRIMIR PEDIDO
- Executar em uma aba mensal (JAN a DEZ).
- Selecionar uma célula dentro do pedido desejado.
- Pedidos começam nas linhas 5, 43, 81, 119... (37 linhas + 1 linha em branco).
- O suplemento seleciona A:M das 37 linhas do pedido. Depois, use Ctrl+P no Excel.

2) NOVO PEDIDO
- Executar em uma aba mensal (JAN a DEZ).
- Insere 38 linhas inteiras.
- Copia o bloco-modelo para o início da aba e limpa os mesmos campos da macro VBA.
- Não cria botões físicos dentro da planilha.

3) IMPORTAR DADOS
- Executar na aba mensal de origem.
- Mantém B50:B74 e D50:E74.
- Envia B50:B74 para a coluna A da BD.
- Envia D50:E74 para B:C da BD.
- Preenche a fórmula na coluna D.
- Não modifica a coluna E da BD.

IMPORTANTE
Teste primeiro em uma cópia do arquivo Excel. Antes de usar em produção, valide especialmente a cópia do pedido, as células mescladas, fórmulas, formatos e validações no Excel Online.
